FAQ

よくある
ご質問

受講前から修了後まで、気になることをまとめました

シュガーフラワー講座を受講される前によく寄せられるご質問を、カテゴリー別にまとめています。

受講前のご質問

Q シュガーフラワーは初心者でも作れますか？

はい。「花ごとのレッスン」と「ビギナー講座」は、初めての方を対象にしています。道具の使い方から丁寧にご説明します。

Q どの講座から始めればよいかわかりません。

まず体験したい方は「花ごとのレッスン」（1日完結）、基礎からしっかり学びたい方は「ビギナー講座」（全8回）がおすすめです。迷う場合はLINEでご相談ください。

Q 年齢制限はありますか？

特に設けていません。中学生以下の方は事前にご相談ください。

Q 必要な道具・材料は何を用意すればいいですか？

すべてご用意しています。手ぶらでお越しください。動きやすい服装をおすすめします。

Q 男性でも参加できますか？

もちろんです。性別は問いません。細かな作業が好きな方に特に向いています。

レッスン・料金について

Q レッスンの料金はいくらですか？

講座の種類・回数によって異なります。現在募集中のページをご確認いただくか、LINEにてお問い合わせください。

Q 体験だけでも参加できますか？

はい。「花ごとのレッスン」は1日完結の単発受講です。気軽に体験いただけます。

Q 欠席した場合はどうなりますか？

ご連絡いただければ振り替え対応いたします。進捗は個別に合わせます。

Q レッスンはオンラインでも受けられますか？

現在はすべて対面レッスンのみです。オンラインでの実施は検討中です。

素材・道具について

Q シュガーペーストとはどんな素材ですか？

砂糖を主成分とした柔らかい粘土状の素材です。伸ばして形を作り、乾燥させると固くなります。食品由来の素材ですが、レッスンで作った作品は食用ではありません。

Q アレルギーがある場合は注意が必要ですか？

シュガーペーストには砂糖・コーンスターチ・ゼラチン・トラガカントガムなどが含まれる場合があります。アレルギーをお持ちの方は事前にご相談ください。

Q ワイヤーは安全ですか？

フラワーワイヤー（細い金属線）を使用します。扱いに慣れれば安全に使えますが、最初は丁寧にご説明します。怪我のないよう配慮しながら進めます。

完成作品について

Q 作品は持ち帰れますか？

はい、すべての完成作品はお持ち帰りいただけます。専用の持ち帰り箱もご用意しています。

Q 作品の保存期間はどのくらいですか？

直射日光・高温多湿を避ければ、数年間きれいに保つことができます。シュガーフラワーは本物の花と違い、劣化しにくいのが特徴です。

Q 食べることはできますか？

レッスンで制作した作品は観賞・鑑賞用であり、食用ではありません。ワイヤーや金属製のアクセサリーが含まれているためご注意ください。
